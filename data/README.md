The included `diabetic_data.csv` is the UCI Diabetes 130-US Hospitals dataset
(1999–2008), DOI: 10.24432/C5230J, distributed under CC BY 4.0.
Source: https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008

It is a de-identified historical teaching dataset. It contains repeated
encounters for some patients. Please cite the source when reusing it.
